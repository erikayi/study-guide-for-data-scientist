### Study guide made it for Data Scientist, Software Engineering, etc. 

# Build a Practical Study Guide 
Create four sections, then study each with a learn > practice > build > review loop. 
##### You can find my live study guide here: https://erikayi.github.io/study-guide-for-data-scientist/ 

# 1. Core Data Science 
- Statistics: probability, distributions, hypothesis testing, confidence intervals
- Math: linear algebra, calculus, optimization 
- Python: NumPy, pandas, visualization 
- Machine learning: regression, classification, clustering, model evaluation 
- Deep learning fundamentals: neural networks, loss functions, backpropagation 
- SQL and data analysis 
- Interview resources: Leetcode-style Python problems, Kaggle exercises 

# 2. Software Engineering 
- Data structures and algorithms 
- Object-oriented design 
- APIs and REST 
- Git and version control 
- Databases and indexing 
- Testing: unit, integration, end-to-end 
- System design basics 
- Debugging, profiling, and code quality 
- Docker and CI/CD fundamentals 

# 3. Use a Repeatable Format 
For every topic, document: 
- Concept: A 2-3 sentence explanation 
- Why it matters: A real data or engineering use case 
- Key formulas or syntax: Keep examples short 
- Python/SQL code: Include a working snippet 
- Common mistakes: Document errors that are easy to make 
- Interview question: Generate 2-3 questions per topic 
- Recall prompt: Turn the content into flashcards 
- Project application: Add one small hands-on exercise 

# 4. Follow a 12-Week Plan 
- Weeks 1-3: Python, SQL, statistics
- Weeks 4-6: Data structures, ML algorithms, model evaluation 
- Weeks 7-9: APIs, databases, testing, Git, Docker
- Weeks 10-12: System design, interview practice, portfolio projects

Spend roughly 60% of study time coding and 40% learning concepts. Revisit difficult topics weekly and end each week with a timed mock interview. 

# 5. Recommended Portfolio Projects
- Predictive model with data cleaning and evaluation 
- SQL analytics dashboard 
- Production-ready REST API 
- End-to-end ML pipeline 
- Data pipeline with Docker and CI/CD 
- System design of a data-driven application
